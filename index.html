ABOUT THE PROJECT

What is Smart Voice Calculator?

Smart Voice Calculator is an Android-based utility application developed using MIT App Inventor. It allows users to perform calculations using both a normal calculator keypad and voice commands.

🎤

Voice Calculation

Speak expressions such as "10 plus 20" and get the calculated result.

🧮

Normal Calculator

Perform basic arithmetic calculations using the on-screen calculator keypad.

🔊

Voice Answer

The application can speak the calculated answer using text-to-speech.
